# 项目路线图

[English](roadmap.md) · [项目目录](../readme.zh-cn.md)

以下项目列出了贡献者下一步可以验证的重点。每个项目的维护者根据实际测试结果决定发布时机。

| 分区 | 下一步 | 验证方法 |
| --- | --- | --- |
| Studio | 验证 Juicer 升级、BrewStore 刷新中断后的恢复，以及 PathDeck 打开期间配置文件被外部修改的情况。 | 在独立的 macOS 测试账号上从旧版本开始，比较取消或恢复操作前后的偏好设置、软件包状态和 shell 配置。 |
| Terminal | 说明 Brew-Ghost 判断软件闲置的依据，并验证 OmniSuite 导出与恢复后仍可追溯引文。 | 使用缺少日期的历史记录与证据库副本。确认用户能够核查软件包处理建议，并能从导出的引文找到来源。 |
| Hangar | 完成 GeoFS 实际飞行验证，检查浏览器工具在宿主页面变化后的表现。 | 记录模拟器版本、机型、操作和实际响应。地图笔记与库存工具使用自己的数据或模拟数据测试。 |
| Arcade | 验证刃影键盘操作与存档流程，测试 FaceOff 房间断线重连和再战。与 VANTAGE 维护者协调发行改动。 | 重连后核对双方比分与状态，每次记录游戏版本、语言和屏幕尺寸。 |
| 软件分发 | 测试从已归档的 tap 迁移至当前 Homebrew tap。 | 保留已有安装并选用非默认应用目录，迁移后核对程序位置与偏好设置。 |
| 网站 | 在项目数据缺失或过期时保持目录可访问。 | 在手机和桌面尺寸下使用键盘及读屏软件，验证语言切换链接、更新日期与各项目入口。 |

各项目的发布版本与待办事项见[项目目录](../readme.zh-cn.md)。通过验收后，发布标签使用小写 v 和语义化版本号。
